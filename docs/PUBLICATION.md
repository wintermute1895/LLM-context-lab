# Publication scope

This repository starts with a clean history and contains only the portable context ledger, CLI/MCP/dashboard code, synthetic examples, and tests.

Excluded from the original local experiment: runtime databases and logs, conversation exports and identifiers, personal filesystem paths, internal project names, customer requirements, task-specific seed scripts, third-party source archives, prebuilt tools, and historical deployment reports.

The tests use temporary repositories and synthetic sessions. They do not require access to a real agent history database. Publishing the code does not sanitize future imported histories or make their contents safe to share.
